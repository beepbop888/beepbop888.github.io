# santoapps

Developer site for the apps published on RuStore by Абрамов Леонард.

It exists for two reasons, both practical:

* **`app-ads.txt`** — the file ad networks read to confirm that the apps in
  the stores really belong to this developer. Yandex generates its contents;
  they are not written by hand.
* **`index.html`** — the privacy policy the store listings link to.

Public on purpose: GitHub Pages only serves free sites from public repos, and
there is nothing here that is not already on a public store listing.
